🧠 Knowledge Platform 대시보드

Human Knowledge & AI Knowledge 이중화 통합 관리 및 승인 관문 UI

💡 Knowledge Platform 지식 관리 3단계 핵심 흐름 가이드

1단계: Q&A 대화 추출 (Draft)

대화 로그에서 지식을 추출하여 AI 오염을 방지하기 위해 .drafts/ 임시 폴더에 격리 저장합니다.

2단계: 인간 검증 및 승인 (Production)

인간 중개자(Human Broker)가 Draft 지식을 검토하고 승인하면 단일 진실 원천(knowledge/)으로 승격 커밋됩니다.

3단계: LLM 에이전트 지식 주입 (Retrieval)

승인 완료된 검증 지식만을 LLM 에이전트 세션에 정밀 주입하여 환각(Hallucination) 없는 답변을 생성합니다.

1. Q&A 대화 지식 추출 및 Draft 생성 (`DSGN-CORE-INGEST`)

Q&A 대화 입력

Q&A 대화 내용 또는 기술 답변을 입력하면 AI가 1개 주제만 포함하는 원자적(Atomic) 마크다운으로 추출하여 .drafts/에 저장합니다.

2. 인간 중개자 검증 및 승인 관문 (`DSGN-APPROVAL-GATE`)

NFR-SEC-01 보안 통제: AI가 자동 생성한 지식(author_type: ai_generated)은 인간의 승인 없이 프로덕션 LLM에 주입될 수 없습니다. 인간 중개자가 검토 후 승인하여 main 브랜치로 병합합니다.

3. Agent 스킬 및 프롬프트 바인딩 (`DSGN-AGENT-BINDER`)

대화 맥락에 따라 필요한 스킬 프롬프트 프리셋 및 Tool Call 스키마를 LLM 대화 세션에 원클릭으로 바인딩합니다.

ingestion

Q&A 추출 & Atomic 작성 프리셋

대화 로그에서 지식을 원자적 마크다운으로 자동 요약 정제하는 스킬 프리셋.

indexer_dag

Ref-DAG 지식 탐색 & Context 주입 프리셋

승인된 지식 그래프를 탐색하여 LLM 세션에 verified 마크다운을 주입하는 스킬 프리셋.

linter_engine

24/7 지식 정적 린팅 감사 프리셋

깨진 링크, Orphan Node, YAML 스키마 오차, Stale 노드를 자동 감지하는 스킬 프리셋.

refactor_engine

그래프 중복 통합 리팩토링 프리셋

유사도 0.90 이상의 파편화 노드를 원자적 1개 노드로 병합 제안하는 스킬 프리셋.

4. 24/7 지식 정적 린팅 & 정합성 검사 (`DSGN-LINTER-ENGINE`)

지식 저장소 정적 린팅 감사 스캔

전체 마크다운 지식 노드와 Ref-DAG 인덱스를 정적 스캔하여 깨진 참조, 고립 노드, 메타 오차를 탐지합니다.

5. Ref-DAG 그래프 탐색기 & Obsidian 연동 (`DSGN-LAUNCHER-PROTOCOL`)

활성 지식 그래프 노드 목록

클릭 시 OS URI Scheme (obsidian://open)을 호출하여 Obsidian 데스크톱 앱에서 해당 지식 파일을 바로 시각화 오픈합니다.
